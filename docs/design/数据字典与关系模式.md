# 数据字典与关系模式

本文件从实际数据库元数据生成。PK 为主键，FK 为外键，UK 为唯一约束或唯一索引。完整 CHECK 表达式位于每张表字段表后。

## 行政区划 area

关系模式：area(id, name, kind, parent_id)。
函数依赖：(id) → 其余属性。

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | int | PK；IDENTITY；NOT NULL | 记录编号 |
| name | nvarchar(60) | NOT NULL | 名称 |
| kind | varchar(10) | NOT NULL | 区划类型 |
| parent_id | int | FK → area.id | 上级区划 |

CHECK：([kind]='district' AND [parent_id] IS NULL OR [kind]='street' AND [parent_id] IS NOT NULL)；([kind]='street' OR [kind]='district')
