# 界面改版记录（2026-11-17）

> 说明：本文记录 16:xx 阶段的界面改造；最终版界面以 [界面改版与操作留痕说明](界面改版与操作留痕说明_20261117.md) 为准。登录页在后续评审中重新加入了照护插画和 `ANLIN · COMMUNITY CARE` 眉题，最终配色也从深色顶栏/陶土蓝调整为浅暖米杏顶栏/暖茶陶土棕，并加入工作台 Hero 线稿；本文旧配色和“去掉插画/英文眉题”的描述仅代表当时阶段。

## 背景

原界面是深绿分栏登录、序号侧栏、四张独立统计卡、柔和圆角与阴影，并配有英文眉题和“让每一份照护……”一类营销文案。课程演示时反馈“AI 味太重”，本轮把界面改成社区养老业务后台的形态：深色顶栏、分组菜单、密集表格、状态标签、少装饰，而不是只换一套配色。

## 改动范围

- 只改前端：`care/templates/index.html`、`care/static/style.css`、`care/static/app.js`。
- 不改：`sql/`、`care/services/`、`care/app.py`、`tests/`、`requirements.txt`、`start.ps1`、数据库对象、接口和权限。
- 页面结构、接口路径、表单字段、列表分页和详情操作保持原样。

## 具体改动

1. **登录页**：去掉 55/45 分栏、绿色插画、英文眉题和营销句式；改为深色系统顶栏 + 居中登录卡；演示账号仍放在折叠区；品牌只出现一次。
2. **工作台骨架**：全宽深色顶栏（系统名、演示环境、日期、角色、退出）；侧栏按“工作台 / 档案与业务 / 服务队伍 / 健康安全 / 系统管理”分组，去掉 01–12 序号。
3. **总览**：四张独立圆角卡改为一条 KPI 横条；订单趋势柱状图改为“服务量统计”表（月份、预约订单、已完成、完成率、合计、口径说明）；待办事项改为三行表格；近期订单保留表格。
4. **列表、详情、表单**：统一 12px 正文、2px 圆角、1px 边框和更紧凑的行高；状态标签改为小方角；按钮、输入框统一 30px 高；详情弹窗使用三列字段，表单保持两列。
5. **文案**：页面说明统一改成名词短语，如“预约、派单、服务确认与结算记录”，不再使用宣传式句子。
6. **响应式**：宽度小于 820px 时顶栏压缩、侧栏变横向菜单、表格在容器内横向滚动；小于 420px 时详情字段改单列。390×844 下 `document.scrollWidth = 390`。
