# 任务与评分对照

依据《社区居家养老智慧服务平台课程设计2026年任务书》及小组、个人报告模板。模板要求比任务书更细的部分，采用模板要求。

| 要求 | 实现与材料 |
| --- | --- |
| 五条业务线的用例和鲁棒分析 | design/diagrams 中 5 张 usecase 图、5 张 robust 图；报告第二章 |
| 局部与全局 UML、关系基数 | 5 张 uml 局部图、global-business 与 global-full 全局图；DOT 和 SVG 源文件 |
| 全部实体属性、类型、约束与取值范围 | 从真实数据库生成的 data_dictionary.json、数据字典与关系模式.md；33 表 276 字段；37 个设计实体到 33 张表的映射见 design/对象与口径映射.md |
| 主码外码、函数依赖、范式分析 | 数据字典逐表标注；报告第四章解释复合键、快照和受控汇总字段 |
| 所有表及索引 DDL | sql/01_schema.sql；报告第五章完整列出 |
| 每表至少 20 条测试数据 | scripts/seed.py；database_inventory.json 逐表计数 |
| 5 条至少连接 3 个关系的查询 | A1、B1、C1、D1、E1 覆盖五条业务 |
| 每业务 3 条 SQL，每条至少 2 种实现 | sql/queries 共 15 组 30 条；参数口径相同，15 组等价性测试（pytest 参数化）+ 1 组 10 万行索引基准，差异说明见设计与验证说明 |
| 持久层 CRUD、分页、批量、事务、并发 | care/db.py、queries.py、services/、tests/；最后一个班次名额竞争测试 |
| 每业务至少 3 个视图 | 档案 3、订单 3、护工 3、健康 4、补贴 4，共 17 个 |
| 每业务至少 1 个过程和 1 个触发器 | 共 11 过程、16 触发器，报告第六章逐项映射 |
| 登录、权限、安全和敏感数据 | PBKDF2、登录锁定、会话超时、CSRF、范围限制、Fernet 加密与 HMAC 检索 |
| 备份恢复及演练 | scripts/backup_restore.py；完整＋差异＋日志恢复、DBCC 与业务汇总核验 |
| 计划分析与索引优化 | 10 万行临时表、两份实际执行计划、7 次测量记录 |
| 截图、源码、测试、答辩 PPT | evidence/screenshots、项目源码、pytest-results.xml、报告目录中的 PPT |
| 成员及分工、个人任务陈述 | 按要求留空，待分工确定后填写 |
| 全员发言录像、会议及教师反馈 | 已提供演示脚本和记录表，实际活动结束后填写和录制 |

评分标准要求真实描述个人贡献和团队协作。现有代码、测试证据及本地版本记录可直接复查，个人贡献和协作记录以实际参与情况为准。
