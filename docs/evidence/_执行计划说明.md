# 执行计划文件说明

`docs/evidence/` 下的 `plan-before.sqlplan` 与 `plan-after.sqlplan` 当前为 **2026-11-17 本轮 benchmark 生成**的执行计划（SQL Server SSMS 可打开的图形计划 XML）。

对应数值在 `query-benchmark-1117.json`：中位耗时 14.335 ms → 0.438 ms；算子由 Clustered Index Scan 变为 Index Seek，估算子树成本 2.19 → 0.0044。

历史基准（2026-11-15）的完整数值保存在 `query-benchmark.json`（16.838 ms → 0.263 ms），其执行计划 XML 未单独留存；数值、7 次原始耗时与算子清单在该 JSON 中完整可查。两份数据结论一致：索引把全表扫描改为索引查找，量级差距稳定。

> 2026-11-17：运行 `scripts/benchmark.py` 时脚本会覆盖同名证据文件，故补充本说明区分两轮数据。
